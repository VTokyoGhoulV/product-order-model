# Product Order Model

Учебная модель товаров, категорий и заказов на Python. Можно загрузить каталог из JSON, найти категорию и рассчитать стоимость заказа с проверкой доступного количества.

**Стек:** Python 3.14, ООП, JSON, pytest, Poetry.

## Основные классы

- `Product` — товар с ценой и остатком. `new_product()` создаёт товар или обновляет существующий с тем же названием.
- `Smartphone` и `LawnGrass` — виды товаров с дополнительными полями.
- `Category` — список товаров и расчёт средней цены.
- `CategoryList` — список категорий с поиском по названию.
- `Order` — заказ одного вида товара с указанным количеством.
- `GetProduct` — итератор, который возвращает строковые описания товаров категории.

Общие интерфейсы заданы абстрактными классами. Миксин `InitMixin` выводит информацию о создании объекта.

## Установка

Нужны Python 3.14 и Poetry.

```powershell
git clone https://github.com/VTokyoGhoulV/product-order-model.git
cd product-order-model
poetry install --no-root --with dev,lint
```

## Пример

Откройте интерпретатор из корня проекта:

```powershell
poetry run python
```

Загрузите каталог из `data/products.json` и создайте заказ:

```python
from src.classes import Order
from src.utils import from_file_to_classes

catalog = from_file_to_classes()
category = catalog.find_by_name("Смартфоны")
order = Order(category.products_list[0], 2)
print(order)
```

После сообщений о создании товаров появится строка:

```text
Заказ: Samsung Galaxy C23 Ultra, 2 шт., Итого: 360000.0 руб.
```

Классы находятся в `src/classes.py`, загрузка JSON — в `src/utils.py`.
`main.py` пока пустой; модель используется через импорт классов.

## Тесты

```powershell
poetry run pytest -q
poetry run pytest --cov=src
```

Тесты проверяют товары, категории, наследование, расчёт заказа и загрузку JSON.

## Ограничения

- Данные хранятся в памяти. Базы данных, интерфейса и сохранения заказов нет.
- Создание заказа проверяет количество, но не уменьшает и не резервирует остаток.
- Конструктор `Product` принимает отрицательную цену. Проверка положительной цены есть только в сеттере `price`.
- При обновлении товара через `new_product()` отрицательное добавляемое количество может сделать остаток отрицательным.
- Реестр товаров и счётчики категорий общие для процесса. Повторная загрузка JSON создаёт дополнительные объекты и увеличивает счётчики.
- Снижение цены через сеттер требует подтверждения в консоли.
